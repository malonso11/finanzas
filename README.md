# Finanzas personales

Herramienta web gratuita para organizar tus finanzas personales a partir de los extractos de tus bancos.

## Privacidad
- Los datos se guardan solo en el navegador del dispositivo donde la usas. La app no tiene cuentas ni servidor propio y no envía tus datos a ningún sitio.
- No usa cookies, publicidad ni analítica.
- Al abrirla, el navegador descarga la app de GitHub Pages y algunas librerías de cdnjs y jsDelivr; esos servicios reciben tu dirección IP, como en cualquier web, pero no tus datos.

- Se ofrece tal cual, sin garantía de ningún tipo. Úsala bajo tu responsabilidad y comprueba siempre las cifras con los documentos oficiales de tu banco.
- No es asesoramiento financiero, fiscal ni de inversión.
- No está afiliada ni respaldada por ningún banco o entidad. Los nombres de bancos y servicios son marcas de sus respectivos titulares y se citan solo para indicar compatibilidad.
